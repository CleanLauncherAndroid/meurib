# مجلد نسخ التطبيق (APKs)

يتم وضع ملفات البناء النهائية للتطبيق (`.apk`) هنا محلياً عند كل عملية تجميع في Gradle عبر المهام:
- `copyDebugApkToApks`
- `copyReleaseApkToApks`

> ملاحظة: قد يُخفي مستعرض الملفات في متصفح AI Studio ملفات `.apk` الثنائية كبيرة الحجم تلقائياً. لتحميل ملف APK أو AAB جاهز على جهازك مباشرة، استخدم **قائمة الإعدادات (أيقونة الترس ⚙️)** أو **قائمة Export** في أعلى الشاشة واختر توليد/تحميل APK.
